# References

> 해커톤 시연용 영유아 제품 안전성 룰체커의 출처와 향후 보강 방향을 정리한 문서입니다.  
> 기준일: 2026-06-12

## 1. 출처 적용 원칙

| 구분 | 사용 방식 | 프로젝트 반영 |
| --- | --- | --- |
| 정부/공공기관 공식 자료 | 룰의 1차 근거 | `ALLERGY_*`, 성분 동의어, 제품/성분 조회 |
| 공공 API | 성분명 정규화 및 제품 신뢰도 보강 | `ingredient_aliases.json`, 향후 API 연동 |

| OCR/제품 라벨 | 실제 입력값 | OCR 실패 시 `UNKNOWN` 처리 |

## 2. 식품 알레르기 룰 근거

| 항목 | 내용 |
| --- | --- |
| 주요 출처 | 식품안전나라: 알레르기 유발 식품 표시에 대해 알아보아요 |
| 보조 출처 | 국가법령정보센터: 알레르기 유발물질 및 혼입 가능성 표시 관련 식약처 법령해석 |
| 적용 대상 | `07_safety_rules.json`의 `ALLERGY_*` 룰 |
| 권장 `source_name` | `식품의약품안전처 알레르기 유발물질 표시대상` |

식약처/식품안전나라 자료는 식품 알레르기를 특정 식품 섭취 시 면역시스템이 과다 반응하여 발생하는 반응으로 설명하며, 두드러기·복통·호흡곤란 등 위험 증상이 동반될 수 있다고 안내합니다. 또한 알레르기 유발 원재료가 사용된 경우 함유량과 관계없이 원재료명 및 별도 알레르기 표시란을 통해 확인할 수 있도록 표시해야 한다는 점을 룰 근거로 사용합니다.

현재 프로젝트에서 반영하는 표시대상은 다음과 같습니다.

`알류`, `우유`, `메밀`, `땅콩`, `대두`, `밀`, `고등어`, `게`, `새우`, `돼지고기`, `복숭아`, `토마토`, `아황산류`, `호두`, `닭고기`, `쇠고기`, `오징어`, `조개류`, `굴`, `전복`, `홍합`, `잣`

> 참고: 법령상 조개류는 굴·전복·홍합을 포함하는 포괄 항목입니다. 시연 데이터에서는 설명 편의를 위해 `조개류`, `굴`, `전복`, `홍합`을 분리했으며, 실제 서비스에서는 중복 안내 제거 정책이 필요합니다.

> 참고(견과류): 식약처 표시대상은 견과류를 카테고리로 묶지 않고 `호두`, `잣`만 명시하며, 아몬드·캐슈넛 등은 한국 의무표시 대상이 아닙니다. 다만 식약처 표시대상은 "라벨 표시 의무" 기준이지 "섭취 안전" 판단이 아닙니다. 보육 현장 안전 도구 특성상 `견과류` 알레르기 아동은 아몬드 등 모든 견과류에 보수적으로 FAIL 처리하는 것이 안전하므로, `ALLERGY_NUT_001`(자체 견과류 주의 사전, trigger `견과류`) 룰로 호두·잣·아몬드·캐슈넛 등을 포괄합니다. 출처는 식약처와 구분해 `자체 견과류 주의 사전`으로 표기합니다.

## 3. 성분명 정규화 출처

| 출처 | 활용 목적 | 예시 |
| --- | --- | --- |
| 식품의약품안전처 식품 원재료 정보 OpenAPI | 식품 원재료명·이명 확인 | `카제인나트륨` ↔ `카제인Na` |
| 식품등의 표시기준 | 식품첨가물 간략명/주용도 확인 | `카제인나트륨`, `카제인Na`, 유화제/증점제/안정제 |
| 식품의약품안전처 화장품 원료성분정보 OpenAPI | 화장품 원료 표준명·영문명·CAS No·이명 확인 | 화장품 성분 동의어 보강 |

현재 `ingredient_aliases.json`은 시연에 필요한 최소 동의어 사전입니다. 이후에는 위 API 응답을 기준으로 별칭을 추가하고, 내부 룰 매칭 전 표준명으로 정규화하는 흐름을 권장합니다.

## 4. 피부 민감/아토피 WARN 룰

| 항목 | 내용 |
| --- | --- |
| 적용 룰 | `SKIN_SENSITIVE_001`, `SKIN_ATOPY_001` |
| 현재 출처 | `자체 주의 성분 사전` |
| 처리 등급 | `WARN` |
| 안내 방식 | 사용 금지 단정이 아니라 소량 사용 후 반응 확인 안내 |

향료, 색소, 에탄올, 페녹시에탄올, 소듐벤조에이트 등은 현재 시연용 주의 성분입니다. 실제 서비스에서는 성분의 사용 목적, 제품 유형, 사용 부위, 아동 개인 프로필, 공공 API 확인 여부를 함께 보여주는 방식으로 보강해야 합니다.

## 5. 초록누리 API 활용 계획

| 항목 | 내용 |
| --- | --- |
| 출처 | 화학제품안전포털 초록누리 OpenAPI |
| 활용 목적 | 생활화학제품 안전정보, 회수대상 제품, 화학물질 특성/유해성 정보 확인 |
| 적용 후보 | 물티슈, 세정제, 클렌저, 생활화학제품 계열 제품 |
| 상태 | 연동 예정 |

화장품 및 생활화학제품 계열 제품의 신뢰도 향상을 위해 초록누리 OpenAPI를 연동할 예정입니다. 다만 초록누리는 생활화학제품 및 화학물질 안전정보 중심의 출처이므로, 화장품 원료 검증은 식약처 화장품 원료성분정보 API 및 제조사 공식 라벨 정보와 병행하는 방향이 적절합니다.
